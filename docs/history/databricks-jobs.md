## Current entry

**DoD 3 is CLOSED: gold runs THROUGH Databricks Jobs as a `dbt_task`.** The project is uploaded to `/Workspace/contoso/gold` with `format=RAW`, a job runs `["dbt run", "dbt test"]` as one task against the warehouse, and this process learns the verdict only from `run_results.json` returned by the Jobs API. Witnessed end to end on a clean stack against the **published** image — pulled, not built here — `ghcr.io/calvinchengx/databricks-emulator:0.2.9` at `sha256:5e9d14b6`: `gold job SUCCESS`, exit 0, five contracts, `129341157.6700 / 2800504.4000 / 474044` — **the Fabric runtime's figures to the last digit**, so moving the execution shape moved no number. **The pin move was never the work, and neither was the rewrite alone**: running gold on the agent the platforms actually use required THREE emulator defects fixed ([#71](https://github.com/calvinchengx/databricks-emulator/pull/71), released **v0.2.9**), on top of the profile-name fix ([#68](https://github.com/calvinchengx/databricks-emulator/pull/68), **v0.2.8**). **(a)** The generated dbt profile carried `-public-url`, the origin advertised to CLIENTS — in compose a host-published address that resolves inside the agent to the agent itself, so dbt never reached the warehouse; `-agent-url` now names the agent-facing origin. **(b)** A dbt failure left as `SystemExit`, which that agent answers by closing the connection, so the caller got `Post /statements: EOF` — a TRANSPORT error on a run where dbt had reported failing tests — and the artefacts, printed first exactly so they would survive, died with the response; the failure is now a FIELD beside the artefacts and nothing raises. **(c)** `spark_env_vars` were accepted by the agent and silently dropped, so `env_var()` in `sources.yml` failed for a variable the task had set; they are now written into the generated code. **None of the three could have been caught by CI**, because `ci:e2e-dbt-task` runs against an agent no platform uses ([#72](https://github.com/calvinchengx/databricks-emulator/issues/72)) — a green gate against something nobody runs, which is the same shape as a witness proving the emulator agrees with itself. The general case of (c), including the `{{secrets/...}}` references that ride on the same field, is [#73](https://github.com/calvinchengx/databricks-emulator/issues/73). **`contracts` is no longer a glob**: the snapshot's names are joined against what dbt actually evaluated, so a contract that exists but did not run is a hard failure rather than a stronger-sounding snapshot — the strictness the Fabric built-in leaf already had.
